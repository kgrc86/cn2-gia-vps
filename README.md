## CN2 GIA 是什么？为什么"CN2"和"CN2 GIA"差这么多

CN2 GIA（Global Internet Access）是中国电信 AS4809 骨干网中的最高档：进出中国的全程走电信自有专线，双向优先调度，这是它晚高峰稳定的根本原因。日常商品页上出现的"CN2"，多数只是 GT 档甚至普通 163 骨干，体验差着级别。

电信体系四档线路，实际表现大致如下：

| 线路 | AS 号 | 实际表现 |
| --- | --- | --- |
| 163 骨干（ChinaNet） | AS4134 | 便宜、容量大，晚高峰丢包可超过 30% |
| CN2 GT | AS4809 | 国内走 CN2 节点、出国后换普通线路；2019 年后不少地区拥堵程度已接近 163 |
| CN2 GIA | AS4809 | 全程专线、双向优先，晚高峰丢包可保持在 0.1% 以下；容量稀缺，批发价最高约 $120/Mbps |
| CTGNet | AS23764 | 新一代网络，实际表现与 GIA 基本相当 |

几个对购买决策有直接影响的数字：GIA 的 IP 转发批发价最高约 $120/Mbps，折算下来 1Gbps 独享理论上一个月成本能到 $10 万量级；163 骨干晚高峰丢包可以超过 30%。这也解释了两件事——特别便宜的"GIA"大概率有水分，以及 GIA 线路没有余量吸收攻击，遭遇 DDoS 时机房通常直接 null route，把你的 IP 临时屏蔽了事。

分辨真假 GIA 最直接的办法是看路由：去程和回程都经过 59.43.x.x 开头的电信节点，才是真 GIA。商品页只写"CN2""CN2 优化"而不写 GIA 的，按 GT 处理就好。

GIA 怕打。线路容量金贵，没有余量吸收攻击，遭遇 DDoS 时机房一般直接 null route。打算跑容易被扫描、容易被打的服务，GIA 并不是合适的承载。

## 常见问题

**怎么确认买到的是真 GIA？**
看路由。去程和回程都经过 59.43.x.x 开头的电信节点才是 GIA；看到 202.97 一类出口的基本是 163 或 GT。商品页明确写 CN2 GIA / GIA-E 的才算数，“CN2 优化”这类模糊措辞默认当 GT 处理。

**CN2 GIA 晚高峰真的稳吗？**
稳，这就是它和 GT、163 的核心区别。同类线路的实测口径下，晚 8 点到 11 点洛杉矶方向延迟维持在 140–180ms，丢包低于 0.1%；同时段 163 骨干丢包可以超过 30%。

**香港、东京的 GIA 为什么贵这么多？**
物理距离近、容量更稀缺，线路成本本身就高。搬瓦工香港 / 东京 Ultra 同规格约为洛杉矶 GIA-E 的 4–6 倍，端口也收紧到 1Gbps（东京 1.2Gbps），这是行业普遍状态，并非某一家故意抬价。

**买错了能退吗？**
搬瓦工全系 30 天退款，足够完成完整的晚高峰实测；DMIT 是 3 天、限 30GB 流量。退款窗口长短在买中国方向 VPS 时值得当作正式条款来看。
